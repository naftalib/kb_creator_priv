[**Architecture.md**](https://github.com/naftalib/kb_creator_priv/blob/main/ARCHITECTURE.md) presents an overview of the general architecture for a knowledge base creator application I developed for our AI integrations team to facilitate effective knowledge base creation from un-chunked documents. The system applies three distinct chunking strategies to generate three temporary knowledge versions, which are scored using Ragas. The most effective strategy is automatically selected as the final product and upserted to Pinecone.

## Experience Building the Application.
- **Research & Prototyping:** Researched optimal tooling, planned, and built the initial prototype. After a few iterations, the prototype was approved by our product manager, and I collaborated with a senior engineer to scale the design into a robust web application. We built each component using Claude Code, implementing continuous testing throughout development.
- **Testing & Architecture Refinement:** Conducted rigorous end-to-end and component-level testing using various AI agents. This identified bottlenecks and drove major architecture overhauls, including API redesigns and optimizing how we integrated Ragas.
- **Post-Launch Stabilization:** Diagnosed and resolved immediate production bugs by analyzing ECS logs with Claude Code and other models to verify root causes.
- **Feature Expansion & Impact:** Continually added new features post-launch, including support for direct pre-chunked document upserts to Pinecone and comprehensive namespace management. The tool is actively used as part of our company's internal AI ecosystem.
